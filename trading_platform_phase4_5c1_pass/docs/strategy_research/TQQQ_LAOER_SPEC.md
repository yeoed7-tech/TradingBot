# TQQQ Laoer research specification

Frozen before the first backtest on this branch. Strategy ID: **laoer_tqqq_bounded_v1**. This is a documented adaptation of the 2021 book-style V1, not a faithful replication or a mixture of V2/V2.1/V4. `laoer_tqqq_original_v1` is reserved and is not implemented.

References: [Laoer, 라오어의 미국주식 무한매수법, 알키](https://ebook-product.kyobobook.co.kr/dig/epd/ebook/E000002955137); [public V1 rule summary](https://jaeminsg.tistory.com/185). The book-style ingredients retained are 40 budget slices, average-cost and generous-limit LOC accumulation, and a full-position 10% profit target. The public summary describes the generous LOC relative to premarket and allows a new purchase on the exit day. We do not have a complete validated premarket dataset or authoritative rules for capital exhaustion. The following deliberately bounded rules govern this experiment, not later variants.

| Rule | Frozen baseline |
|---|---|
| Universe, capital | TQQQ, USD spot cash, no borrowing/FX trades; USD 10,000 virtual account, max cycle allocation 100% in the research baseline; same opening capital for comparisons |
| Clock | NASDAQ regular session in America/New_York; authoritative historical exchange calendar including holidays/early closes. Session decisions use the observed opening mark, before close; no after-hours orders |
| First purchase | Spend at most one slice at the observable opening price plus simulated adverse execution cost. This approximates post-open entry; no same-bar sale is eligible from this entry |
| Accumulation | Every eligible trading session, at most one daily tranche; one half-slice LOC at pre-session fee-inclusive average cost, one at opening mark + 10%. Both limit prices round down to the tick. Size whole shares using limit price and fee reserve, not closing price. Do not carry unfilled DAY orders |
| Full exit | Existing position at session start gets a DAY sell limit at average cost × 1.10, gross of exit costs. Round up to tick. Open at or above the limit plus adverse slippage buffer or intraday high strictly above that buffered trigger can fill in simulation; no guarantee about auction capacity or live fills |
| Conflict rule | Exit considered before close buys. Any exit fill suppresses close buys that day. No new cycle until the next eligible session. This is an explicit simulator contingency; safe live implementation would require confirmed cancel/state, not simultaneous unconditional orders |
| Accounting | Common Decimal Portfolio; average = remaining cost / shares (entry fees included). Sale fees reduce realized PnL. Cash bucket is USD. Cash distribution receivables tracked separately; no reinvestment when pay dates unavailable |
| Limits | Cycle budget fixed at cycle start (allocated fraction of available USD). Each filled daily tranche counts once across both legs and partial fills. Max 40 filled tranches, never recycle sales within an open cycle. Risk may cap/deny orders separately |
| Exhaustion | Halt additional buys when tranche count, cash or remaining cycle budget prevents a minimum-share order. Preserve exit and mark-to-market; no automatic loss sale, reset, top-up, or later-version rescue rule |
| Partial/duplicate fills | One immutable ID per simulated fill, deterministic order ID per cycle/session/leg. Partial fill uses actual size, consumes the tranche only once. Conflicting duplicate or unknown fill halts; remainder expires at session close. Partial sell leaves the same cycle open |
| Split | Use date-correct raw price scale; multiply share quantity at split and preserve total cost. Research supports integer forward splits; unsupported events fail closed. Split and distribution events processed once before session decisions |
| Recovery | Persist cycle ID, immutable config hash, opening budget, spend, session/tranche/fill IDs, order state and common portfolio/risk state. Resume a committed simulation checkpoint, never resend an ambiguous external order |
| OOS | Development 2010–2018, validation 2019–2021, historical holdout 2022–latest complete downloaded session. Same frozen baseline for all. Walk-forward: annual independent evaluation windows 2015 onward, trailing 3 years of contextual history, no parameter selection, fresh cash. Development-only sensitivity. Retrospective holdout is not prospective validation |

The baseline must beat **cash on net CAGR**, show **holdout MDD no worse than 35%**, and have **positive net returns in at least 60% of annual evaluation folds** before further paper consideration; these are screening criteria, not guarantees. TQQQ/QQQ Buy & Hold are comparison portfolios with different exposures, not risk-equivalent hurdles. Default model costs: 5 bp fee and 5 bp adverse slippage per side; optional FX costs separately. Report actual modeled cash exhaustion and unfinished cycle losses. All use is research or simulation.
